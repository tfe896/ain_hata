# Godlike × AIN — дизайн-концепт для Figma (під Webflow)

Локальний Figma-плагін, який за один запуск збирає у файлі повний дизайн-концепт лендінгу:

- **🖥 Desktop 1440**: усі 15 секцій, шапка, 2 бігучі рядки, фонові світіння, відкрите меню поруч.
- **📱 Mobile 390**: та сама сторінка в мобільній версії.
- **🧩 Дизайн-система**: кольори (змінні `Godlike / colors`), 52 текстові стилі (Desktop/Mobile), компоненти: кнопка, кнопка меню, картки, пігулки.
- **📋 Інструкція Webflow**: як переносити макет і які атрибути анімацій ставити.

Макет зібраний на Auto Layout, назви шарів відповідають класам Webflow. Рожеві мітки праворуч від макета показують, де які анімації (`data-anim`, `data-scene`, `data-count` …).

## Як запустити (≈2 хвилини)
1. **Шрифт.** Встановіть на комп'ютер чотири файли з папки `fonts/` (подвійний клік → Встановити). Якщо Figma Desktop вже відкрита, перезапустіть її. Без Gilroy плагін тимчасово підставить Inter.
2. Відкрийте у **Figma Desktop** файл «Godlike × AIN — лендінг (дизайн-концепт під Webflow)» (Drafts) або будь-який порожній файл.
3. Меню **Plugins → Development → Import plugin from manifest…** і виберіть `manifest.json` з цієї папки.
4. **Plugins → Development → Godlike × AIN — Webflow concept**. Плагін працює 10–40 секунд і закривається з повідомленням «Готово…».

Запускайте один раз на порожньому файлі: повторний запуск додасть ще один комплект сторінок.

## Для розробника
- `src/code.src.js`: вихідний код плагіна. `data/content.json`: тексти, витягнуті з `godlike-landing/index.html`. `data/assets.json`: стиснені фото, логотипи й статичні кадри 3D-фігур.
- `python3 build.py` збирає `code.js` (вбудовує контент і картинки).
