# AIN Awards 2026 — сертифікат Molfar Intelligence (Figma-плагін)

Локальний плагін, який за один запуск збирає у Figma макет сертифіката на три призи від Molfar Intelligence
(Background check, курс з OSINT, місяць доступу до Minos) у візуальній мові AIN Awards 2026: чорна основа,
червоні відблиски, скляні картки, мʼятний акцент. Макет **A4 landscape, 1754×1240**, усе редагується (текст, Auto Layout там, де є стеки).

## Запуск (≈1 хвилина, не витрачає ліміт Figma MCP)
1. Створіть **порожній** файл у **Figma Desktop** (у файл «AIN (general)» не потрібно).
2. **Plugins → Development → Import plugin from manifest…** → `manifest.json` з цієї папки (поруч має лежати `code.js`).
3. **Plugins → Development → AIN Awards 2026 — сертифікат Molfar**. Макет зʼявиться праворуч від наявного вмісту.

Шрифти: заголовки й текст — **Basis Grotesque Pro**, моно-мітки — **JetBrains Mono** (або Roboto Mono / IBM Plex Mono).
Якщо шрифту немає, плагін підставить Inter і напише про це в повідомленні. Після цього шрифт можна змінити виділенням усіх текстів.

## Що замінити вручну
- **Логотип AIN** у правому верхньому куті — наближення з двох форм (`AIN logo (замінити на оригінал)`). Підставте справжній.
- Поля «Нагороджується», «Номер», «Активувати до» — приклади, вписуються на кожного отримувача.

## Редагування тексту
Усі тексти — в обʼєкті `TXT` на початку `spec.js`. Після змін: `python3 build.py` (оновить `code.js`) і запустіть плагін знову.
`preview.html` — той самий макет у браузері для швидкої перевірки (`preview-landscape.png` — знімок).

## Як це влаштовано
`spec.js` — єдиний опис сцени → `figma-render.js` (Figma API) і `html-render.js` (прев'ю). `build.py` склеює `spec.js` + `figma-render.js` у `code.js`.
