# Лендінг у Webflow (нативна версія)

Сторінка `/godlike-native` на сайті «Taras's Beautiful Site» зібрана з рідних елементів Webflow: секції, заголовки, абзаци, кнопки й картинки редагуються в Designer. Анімації та 3D-фігури підключаються одним Embed внизу сторінки з цього репозиторію (через jsDelivr, зафіксовано на коміті).

## Що можна правити у Webflow без коду
- **Тексти:** будь-який заголовок, абзац, цитата, підпис картки.
  Градієнтні слова в заголовках — це Span з класом `gt` всередині заголовка.
- **Цифри в картках** («13+», «20 000+», «#23», «~2 хвилини»). Лічильник сам рахує до того значення, яке написане.
- **Посилання кнопок** `cta` (Link Settings).
- **Фото** в цитатах і блоці «Ігор»: елементи Image, файл міняється в налаштуваннях картинки.
- **Порядок і кількість** карток, пігулок, абзаців. Нові абзаци анімуються, якщо в Settings → Custom attributes додати `data-anim` = `words`.
- **Назви пунктів меню:** атрибут `data-menu` у секції. Меню будується автоматично з секцій.

## Чого не робити
- Не видаляти й не перейменовувати атрибути `data-anim`, `data-count`, `data-scene`, `data-stream`, `data-marquee`, `data-menu`.
- Не перейменовувати класи `sec`, `wrap`, `split`, `col`, `fig`, `glass`, `stat`, `card`, `marq`, `track`, `top`, `mbtn`, `cta`.
- Не видаляти Embed внизу сторінки: у ньому стилі та скрипти анімацій.

## Атрибути
| Атрибут | Що робить |
|---|---|
| `data-anim="letters"` | заголовок з'являється по літерах |
| `data-anim="words"` | абзац або цитата з'являється по словах |
| `data-anim="scrub"` | великий текст підсвічується слово за словом під час скролу |
| `data-anim="reveal"` | блок плавно з'являється, коли потрапляє на екран |
| `data-count` | число рахує від нуля до написаного значення |
| `data-scene="0…13"` | 3D-фігура; картинка `fig-poster` всередині показується, поки фігура не готова, і на пристроях без WebGL |
| `data-stream` | «потік даних» на першому екрані |
| `data-marquee="l"` / `"r"` | бігучий рядок (елементи всередині `track` скрипт повторює сам) |
| `data-menu="…"` | назва секції в меню |
| `data-fallback` | у картинок: адреса копії файлу в репозиторії, яка показується, поки у Webflow не вибрано файл з Assets |

## Як оновлювати код анімацій
1. Змінити файли в `godlike-landing/js` або `css`, закомітити й запушити.
2. У Embed на сторінці замінити хеш коміту в усіх п'яти посиланнях і опублікувати сайт.

## Файли
- `js/webflow-native.js`: адаптер, який перетворює звичайний текст з Webflow на розмітку для анімацій.
- `webflow/native-body.html`: та сама розмітка, що у Webflow (генерується `webflow/mknative.js` з `index.html`).
- `webflow/build_webflow.py`: ріже її на секції та робить CSS для класів Webflow (вигляд у Designer).
- `native-test.html`: локальна перевірка нативної версії.
