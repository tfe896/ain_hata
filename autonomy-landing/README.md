# AIN × MII — «Автономна далекобійна зброя РФ» (спецпроєкт)

Лендінг зібраний у Webflow (сайт `kayt`, сторінка `/autonomous-weapons`) нативними елементами. Анімації підключає один Code Embed унизу сторінки з цього репозиторію через jsDelivr із зафіксованим комітом.

## Що де
- `webflow/style.css` — класи Webflow (макет, типографіка, адаптив). Джерело для Designer.
- `webflow/sections/*.html` — розмітка секцій (та сама, що вставлена у Webflow).
- `css/app.css`, `js/app.js` — анімації й фірмовий мотив МІІ (смужки). Підключаються Embed-ом.
- `video/`, `poster/` — стиснені відео тестів «Альбатроса» й постери (грають на сторінці).
- `webflow/build_test.py` → `test/index.html` — локальна імітація сторінки (відкрити у браузері).

## Бренд (брендбук МІІ)
Dark Green `#0C5350`, Light Green `#55BFAC`, Black `#141414`, White, Yellow `#FCE881` (акцент). Шрифт брендбуку — Taktika Sans (платний). Зараз Onest + JetBrains Mono (Google Fonts) як заміна; щоб підключити Taktika Sans, завантажити файли шрифту в Webflow → Site settings → Fonts і змінити `font-family` у класі `page`.

## Атрибути (керують анімаціями; не видаляти й не перейменовувати)
| Атрибут | Що робить |
|---|---|
| `data-anim="words"` | заголовок/абзац з'являється по словах |
| `data-anim="reveal"` | блок плавно з'являється |
| `data-anim="scrub"` | текст підсвічується слово за словом під час скролу |
| `data-count` | число рахує від нуля до написаного значення (`400 ГБ`, `50 000+`, `5,6 млн ₽`) |
| `data-bar` + `data-max` | смужка шкали: ширина = `data-bar` / `data-max` |
| `data-img` | зображення відкривається «жалюзі» зі смужок |
| `data-marquee="l\|r"` | бігучий рядок |
| `data-stripes` | полотно зі смужками на першому екрані |
| `data-steps`, `data-stage`, `data-step`, `data-node`, `data-link` | блок «людина в петлі» |
| `data-video` + `data-name` | відео (файл у `video/`, постер у `poster/`) грає лише на екрані |
| `data-target="Назва"` | мітка прицілу під курсором |

Класи Webflow не перейменовувати. Тексти, цифри й фото редагуються у Designer вільно.

## Оновлення коду
Змінити `js/` або `css/`, закомітити й запушити, у Embed замінити хеш коміту в посиланнях.
