# AIN × UGB — 2 слайди (бейджі, сцена)

Окремий маленький плагін: створює лише два оновлені слайди, щоб вставити їх у вже існуючу презентацію.
- **07 — Бейджі:** фото бейджів з події + нове фото 9 бейджів (обрізане без сірого фону).
- **09 — Сцена (екрани):** фото сцени + 3 екрани біля сцени, наближені так, щоб читалися логотипи.

Запуск: Figma Desktop → Plugins → Development → Import plugin from manifest… → `manifest.json` з цієї папки → запустити.
У Figma Slides обидва слайди з'являться окремим рядом у кінці сітки: перетягніть їх на місце старих 7 і 9, а старі видаліть.

Збирається з тих самих джерел, що й повний звіт: `python3 build.py two`.
