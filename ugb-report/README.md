# AIN × UGB — звіт «Українська енергетика» (оновлена презентація)

Локальний Figma-плагін. За один запуск додає повну оновлену презентацію: 39 слайдів 1920×1080 у дизайні попередньої (шрифт Noto Sans, лого AIN × UGB, чорні пігулки, червоний акцент).
- **Figma Slides:** 39 слайдів **окремим рядом у кінці** сітки, у правильному порядку. Старі слайди не змінюються: переглянете нові й видалите старий ряд.
- **Figma Design:** нова сторінка «Звіт UGB — оновлено …».

## Як запустити
1. Відкрийте презентацію у **Figma Desktop**. У браузері локальні плагіни не запускаються.
2. Якщо плагін уже імпортували раніше: Plugins → Development → Manage plugins in development → видаліть стару версію.
3. **Plugins → Development → Import plugin from manifest…** → `manifest.json` з цієї папки.
4. Plugins → Development → **AIN × UGB — звіт (оновлення презентації)** → оберіть команду:
   - **Усі 39 слайдів** — вся презентація новим рядом;
   - **Лише виправлені слайди: 6, 9, 10** — тільки ці три слайди новим рядом; замініть ними відповідні слайди у своєму файлі, ручні правки решти слайдів не зачіпаються.

- **Слайд 7:** коли буде нове фото бейджа, замініть фото: виділити → Fill → Image.
- **Слайд 3:** кількість гостей (120).

## Для розробника
- `src/code.src.js` — плагін (тексти, посилання, розкладка). `python3 build.py` → `code.js`.
- `tools/prep_assets.py` → `data/assets.json`. Джерела: рендер PDF (`pdftoppm -r 144`), оригінальні картинки з PDF (`pdfimages -j -p`) з їхніми координатами (`orig/boxes.json`, через pdfplumber), 5 фото події з Google Drive, скріни сторіз і листа розсилки.
- `node tools/preview.js code.js <папка зі шрифтами NotoSans-*.ttf> <out> [slides|figma]` — виконує плагін у Chromium на імітації Figma API з реальним шрифтом і робить PNG кожного слайда. Повідомляє, якщо щось виходить за межі слайда.
