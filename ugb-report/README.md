# AIN × UGB — звіт «Українська енергетика» (оновлена презентація)

Локальний Figma-плагін. За один запуск він додає повну оновлену презентацію: 38 слайдів 1920×1080 у дизайні попередньої.
- **Figma Slides:** слайди додаються **окремим рядом у кінці** сітки слайдів. Старі слайди не змінюються: переглянете нові й видалите старий ряд.
- **Figma Design:** створюється нова сторінка «Звіт UGB — оновлено …».

## Як запустити (≈1 хвилина)
1. Відкрийте презентацію (Figma Slides) у **Figma Desktop**. У браузері локальні плагіни не запускаються.
2. **Plugins → Development → Import plugin from manifest…** → виберіть `manifest.json` з цієї папки.
3. **Plugins → Development → AIN × UGB — звіт (оновлення презентації)**. Через 10–30 секунд з'явиться повідомлення «Готово: 38 слайдів…». Якщо плагін уже імпортували раніше (до підтримки Slides), видаліть його в Plugins → Development → Manage plugins in development і імпортуйте `manifest.json` заново.

Шрифт — Noto Sans, як у презентації. Якщо його немає, плагін тимчасово підставить Inter і напише про це.

## Що доробити вручну
- **Слайд 7:** у рожеву рамку вставити нове фото бейджа: виділити рамку → Fill → Image.
- **Слайд 15** (рекламні креативи Facebook): у старій презентації не було посилання, на його місці рожевий текст «[додайте посилання]».
- **Слайд 3:** перевірити кількість гостей (зараз 120).
- Слайди 26–38 вставлено як зображення оригіналів. Шапку з посиланням «Сайт AIN» на них перекрито живими пігулками, щоб посилання працювало. Якщо потрібні редаговані оригінали, перетягніть їх зі старої сторінки.

## Для розробника
- `src/code.src.js` — код плагіна (тексти, посилання, розкладка слайдів).
- `data/assets.json` — стиснені картинки. Збирає `tools/prep_assets.py` з рендеру PDF, з оригінальних фото, витягнутих з PDF через `pdfimages`, а також з 3 фото події з Google Drive, скрінів сторіз і листа розсилки.
- `python3 build.py` → `code.js`.
- `node tools/mock_run.js code.js <папка>` (з `EDITOR=slides` — режим Figma Slides) проганяє плагін на імітації Figma API і малює приблизні SVG-прев'ю слайдів.
