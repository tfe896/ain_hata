# AIN — звіт для партнерів дослідження «Українська енергетика»

Загальна версія звіту без прив'язки до Укргазбанку, для всіх партнерів дослідження. 27 слайдів 1920×1080 у тому ж дизайні.

Відмінності від звіту для Укргазбанку:
- у лівому куті лише лого AIN (без лого UGB), зокрема й на підсумковому слайді;
- назви слайдів: «Прояви партнерів: …» замість «Прояви партнера Укргазбанк: …»;
- прибрано слайд зі стендом Укргазбанку;
- прибрано блок «Експертиза в дослідженні» (коментарі та кейси Укргазбанку, слайди 27–38 банківського звіту);
- додано слайд «банер дослідження на сайті AIN» зі статистикою (одразу після «дослідження на сайті AIN»).

Лишилось як є: програма й спікери події (серед них представник Укргазбанку — це факт програми), обкладинка дослідження й скріни з рядком партнерів (ain, ugb, Ecotech Invest, KTS engineering) — це оформлення самого дослідження.

Запуск: Figma Desktop → Plugins → Development → Import plugin from manifest… → `manifest.json` з цієї папки → запустити.
У Figma Slides 27 слайдів з'являться окремим рядом у кінці сітки; у Figma Design — на новій сторінці.

Збирається з тих самих джерел, що й звіт для банку: `python3 build.py general`.
