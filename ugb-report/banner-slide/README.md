# AIN × UGB — слайд «Банер на сайті AIN»

Окремий плагін: створює один слайд у дизайні звіту — топ-банер дослідження на головній ain.ua і статистика кампанії (23.10–25.11.2026, охоплення 70 089).

Запуск: Figma Desktop → Plugins → Development → Import plugin from manifest… → `manifest.json` з цієї папки → запустити.
У Figma Slides слайд з'явиться окремим рядом у кінці сітки; перетягніть його на потрібне місце (логічно — після слайда «дослідження на сайті AIN»).

Збирається з тих самих джерел, що й повний звіт: `python3 build.py banner`.
