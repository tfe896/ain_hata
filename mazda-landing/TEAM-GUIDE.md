# Mazda × Співпраця: що можна правити у Webflow (для команди)

Сторінка автономної версії: `/mazda-spivpratsia-standalone`. Старий варіант із кодом на GitHub (`/mazda-spivpratsia`) лишається окремо.

> Увага: кроки пункту 2 написані без доступу до Designer (працювали через API). Перед тим як віддавати інструкцію команді, нехай хтось один пройде її на тестовій копії сторінки й поправить назви розділів меню Webflow.

## 1. Тексти, цифри, фото, посилання: код не чіпаємо
- Відкрити сторінку в Designer і правити елементи як звичайно.
- **Цифри-лічильники** (2500, 5 тощо): міняється лише число в тексті, анімація підхопиться сама.
- **Фото:** Image → Replace. Розмір і пропорції краще лишати тими самими, інакше кадр може зсунутися.
- **Відео й карта:** посилання лежать в атрибутах `data-video`, `data-video-mobile` (для телефона) і `data-map` на відповідних блоках. Новий файл спершу завантажити в Assets, потім вставити його посилання в атрибут.
- Класи `mz-…` і атрибути `data-anim`, `data-shot`, `data-count` не видаляти й не перейменовувати: за ними скрипт знаходить елементи.

## 2. Змінити саму анімацію: це правка коду
Анімації не є Webflow Interactions, у Designer їх не видно. Код лежить у двох файлах в Assets: `mazda-style-v1.js` (стилі) і `mazda-anim-v1.js` (логіка). Прямо в Webflow їх правити не можна, лише замінити файл:
1. Завантажити нову версію файлу в Assets з новою версією в назві (`…-v2.js`), старий не видаляти.
2. У налаштуваннях сайту підставити в підключення скрипта новий файл (і новий SRI-хеш, якщо Webflow його вимагає). Шукати розділ Custom code.
3. Опублікувати. Для відкату повернути старий файл `v1`.

Файли редагує той, хто знає JavaScript. Джерело: `mazda-landing/site/js/mazda.js` і `css/anim.css` у репозиторії; файли в Assets це зібрана мінімізована копія (`shared/webflow-tools/build_files.py`), руками їх правити не варто. Технічні кроки з API: `mazda-landing/README.md`, розділ «Автономна версія».

## 3. Що не чіпати
- Варіант із GitHub (`/mazda-spivpratsia`) лишається окремо.
- Зареєстровані скрипти `mzaboot`, `mzbcss*`, `mzdjs*`, `mzerun` (15 штук) ніде не підключені; видаляти їх не потрібно.
