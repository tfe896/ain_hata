# Mazda × Співпраця — лендінг

## figma-plugin — дизайн-концепт (r2)

Локальний Figma-плагін, який за один запуск будує у **будь-якому** файлі дизайн-концепт екранів 1–3:

- **🖥 Desktop 1440 · r2**, **📱 Mobile 390 · r2**, **🧩 Стилі · r2** (нові сторінки; якщо план не дає створити сторінки, усе з'явиться на поточній сторінці поруч);
- змінні кольорів `Співпраця × Mazda / colors r2`, текстові стилі `Mazda r2/Desktop/…` і `Mazda r2/Mobile/…`;
- Auto Layout, назви шарів = класи Webflow, рожеві мітки анімацій праворуч від макета.

Картинки (кадр hero, логотипи) і карта вбудовані в `code.js`, інтернет плагіну не потрібен.

### Запуск
1. Для запуску потрібні лише два файли: `manifest.json` і `code.js` в одній папці (якщо це архів, спершу розпакуйте його).
2. Відкрийте потрібний файл у **Figma Desktop** (у браузері локальні плагіни не працюють).
3. **Plugins → Development → Import plugin from manifest…** → `manifest.json`.
4. **Plugins → Development → Mazda × Співпраця — дизайн-концепт (r2)**. За кілька секунд унизу з'явиться «Готово…».

Шрифти: заголовки — GT Pressura LC Bold (має бути встановлений на комп'ютері), текст — Inter Tight. Без GT Pressura плагін підставить Inter Tight і попередить про це в повідомленні.

Кожен запуск додає новий комплект сторінок, тож запускайте один раз на файл. Якщо з'явилося «Помилка на кроці …», надішліть цей текст.

### Заглушки, які треба замінити
- горизонтальний логотип Mazda зібраний із вертикального файлу, потрібен офіційний;
- фото у фактоїдах і полароїдах — кадр із hero-відео;
- текст і посилання продуктової вставки;
- шрифт у пігулках — Inter Tight; якщо в айдентиці там інший, замінити.
