# Mazda × Співпраця — лендінг

## figma-plugin — повний концепт (r3)

Локальний Figma-плагін, який за один запуск будує у **будь-якому** файлі повний дизайн-концепт сторінки:

- **🖥 Desktop 1440 · r3**, **📱 Mobile 390 · r3**, **🧩 Стилі · r3** (нові сторінки; якщо план не дає створити сторінки, усе з'явиться на поточній сторінці поруч);
- змінні кольорів `Співпраця × Mazda / colors r3`, текстові стилі `Mazda r3/Desktop/…` і `Mazda r3/Mobile/…`;
- Auto Layout, назви шарів = класи Webflow, рожеві мітки анімацій праворуч від макета.

Структура сторінки (повний текст авторки):
1. `header` — автор проєкту, за підтримки, автомобільний партнер;
2. `sec hero (video)` — постер відео `Mazda1.mp4`, лого проєкту, h1 у три рядки, підзаголовок;
3. `sec intro` — лід, вступ, три фактоїди з фото;
4. `sec feature space` — «Простір для всієї команди й обладнання», полароїди, факт «3 ряди сидінь»;
5. `sec route` — карта маршруту й зупинки + «Для міських вулиць, трас і гірських доріг» із трьома полароїдами (місто, траса, гори);
6. `sec handling (photo)` — «Керованість на звивистих дорогах» на фото серпантину, факти «200 км» і «5+ м»;
7. `sec team` — «Автомобіль як частина великої команди», цитати Геннадія Сухарнікова та Юлії Лободюченко, продуктова вставка Mazda CX-90.

Картинки й карта вбудовані в `code.js`, інтернет плагіну не потрібен.

### Запуск
1. Для запуску потрібні лише два файли: `manifest.json` і `code.js` в одній папці (архів спершу розпакуйте повністю).
2. Відкрийте потрібний файл у **Figma Desktop** (у браузері локальні плагіни не працюють).
3. **Plugins → Development → Import plugin from manifest…** → `manifest.json`.
4. **Plugins → Development → Mazda × Співпраця — повний концепт (r3)**. За кілька секунд унизу з'явиться «Готово…».

Шрифти: заголовки — GT Pressura LC Bold (має бути встановлений на комп'ютері), текст — Inter Tight. Без GT Pressura плагін підставить Inter Tight і попередить про це в повідомленні.

Кожен запуск додає новий комплект сторінок, тож запускайте один раз на файл. Якщо з'явилося «Помилка на кроці …», надішліть цей текст.

### Що ще треба звірити або замінити
- **Правило проєкту:** концепт робимо виключно за текстом авторки. Маршрут на карті й у зупинках відповідає тексту: Київщина, Полтавщина, Закарпаття, Карпати, дорога назад до Києва; Львова в тексті немає, тому його немає й на карті. На карті, у зупинках і в заголовку маршруту пишемо «Карпати», а не «Верховина» (рішення замовника).
- Горизонтальний логотип Mazda зібраний із вертикального файлу, потрібен офіційний.
- Текст і посилання кнопки у продуктовій вставці — заглушки; референс вставки з минулих спецпроєктів від Поліни ще не отримано.
- Шрифт у пігулках — Inter Tight; якщо в айдентиці там інший, замінити.
- Припущення: автор проєкту — AIN, за підтримки — KredoBank. Фото до цитат ведучих підтверджено.
- Факти в помаранчевих плашках («3 ряди сидінь», «200 км серпантинів», «5+ м») узято з тексту; погодити з клієнтом.

## site — сторінка у Webflow й анімації

Сторінка: сайт Webflow `6aec9fbcb1bc39fcfd02af09` («Taras's Site»), сторінка `/mazda-spivpratsia` (id `6af4b6b58b371d14f88324e3`), опублікована на `tarass-beautiful-site-32778b.webflow.io/mazda-spivpratsia`.

- **Розмітка** — рідні елементи Webflow з класами `mz-*` (префікс, щоб не зачепити класи Godlike на тому самому сайті). Джерело: `site/src/body.html`, стилі класів: `site/css/layout.css`.
- **Картинки** — в Assets сайту (`site/webflow/assets.json`: локальний файл → ім'я ассету). Відео `hero.mp4` і `map.svg` беруться з цього репозиторію через jsDelivr.
- **Шрифти** — GT Pressura LC Bold завантажено у шрифти сайту; Inter Tight підключається з Google Fonts.
- **Код анімацій** — `site/js/mazda.js` + `site/css/anim.css`. На сторінці два зареєстровані скрипти: `mazda_loader` (у head: шрифти, anim.css, запобіжник) і `mazda_animations` (перед `</body>`: `mazda.js` з jsDelivr на зафіксованому коміті, з SRI).

### Що анімовано
| Атрибут / клас | Що робить |
|---|---|
| заставка | помаранчевий екран: штамп «Співпраця» впечатується, лічильник 0 → 2500 км, завіса їде вгору, штамп летить на місце в заголовку |
| `data-anim="lines"` | заголовок першого екрана: рядки виїжджають з-під маски, числа рахуються від нуля |
| `data-anim="letters"` | заголовки з'являються по літерах |
| `data-anim="words"` | абзаци й цитати з'являються по словах |
| `data-anim="scrub"` | лід «проявляється» слово за словом під час скролу |
| `data-anim="reveal"` | блок плавно з'являється (сусідні — по черзі) |
| `data-count` | число рахує від нуля до написаного значення («2500+», «200 км», «5+ метрів») |
| `data-shot` | полароїд «падає» на місце, легкий паралакс, реакція на наведення |
| `data-video` | фонове відео першого екрана (картинка всередині — постер) |
| `data-video-mobile` | легка вертикальна версія ролика для екранів до 767 px (`assets/hero-m.mp4`); без атрибута скрипт сам шукає `hero-m.mp4` поруч із `hero.mp4` |
| `data-map`, `data-pins` | карта: маршрут малюється під час скролу, області й зупинки підсвічуються по черзі; `data-pins` — підписи точок через `|` |

Редактори можуть вільно міняти тексти, цифри, фото й посилання. Не видаляти атрибути `data-*` і не перейменовувати класи `mz-*`.

### Локальна перевірка й оновлення
- `python3 site/build.py` збирає `site/index.html` (відкривати через локальний сервер). Для заголовків покласти `GT-Pressura-LC-Standard-Bold.woff2` у `site/fonts/` (у репозиторій не комітимо).
- `python3 site/build.py <commit>` готує `site/webflow/out/*` (розмітка секцій і CSS для вставки у Webflow).
- Телефони й планшети (клас `mz-touch` на `<html>`): паралаксу й смуги прогресу немає, полароїди лише проявляються; висота першого екрана в `svh` (не стрибає з адресним рядком iOS); маршрут на карті тільки «росте» й не гасне при прокрутці назад.
- Зараз на сторінці версія скриптів 1.1.0, коміт `9afc0e3`; при зміні коміту оновити також `data-video` і `data-video-mobile` на першому екрані.
- Оновлення коду анімацій: коміт і push → у Webflow оновити скрипти `mazda_loader` (посилання на anim.css) і `mazda_animations` (посилання на mazda.js + новий SRI `openssl dgst -sha384 -binary … | openssl base64 -A`), нова версія → застосувати до сторінки → Publish.
- Нові картинки: `create_asset` через Webflow MCP → завантаження у S3 (скрипт на кшталт `wfup.py`: політика підпису відтворюється з дати, ключа й типу) → `set_image_asset` на елементі.

## Автономна версія (код усередині Webflow, без GitHub)

- Сторінка `/mazda-spivpratsia-standalone` (id `6af57eecd17e817cf8a30486`) — копія `/mazda-spivpratsia`; та сторінка й її код на jsDelivr лишаються як є.
- Принцип такий самий, як у команди AIN: код — файли в Webflow Assets із версією в назві. `webflow/standalone/mazda-style-v1.js` (head: клас-запобіжник, шрифт Inter Tight, стилі анімацій) і `mazda-anim-v1.js` (перед `</body>`: уся логіка). Обидва зібрані `python3 webflow/build_standalone.py files v1` з `css/anim.css` і `js/mazda.js` (terser) і підключені двома зареєстрованими hosted-скриптами `mazdastylev1` / `mazdaanimv1` із SRI.
- Відео (`mazda-hero.mp4`, `mazda-hero-m.mp4`) і карта (`mazda-map.svg`) лежать у Webflow Assets; посилання в атрибутах `data-video`, `data-video-mobile`, `data-map`. На опублікованій сторінці жодних посилань на GitHub/jsDelivr.
- Оновлення коду: правка `js/mazda.js` / `css/anim.css` → `build_standalone.py files v2` → `create_asset` для нових файлів (ім'я з новою версією) + `wfup.py` (завантаження в S3) → перевірити хеші з CDN → `register_hosted_script` (нова версія, SRI) → `set_page_scripts` → Publish. Старий файл залишається на CDN, тож відкат — повернути стару версію.
- Webflow API не дає писати вільний кастомний код, але приймає `.js` як ассет: цим користуємося замість першого варіанта (15 шматків по 2000 символів, зареєстровані скрипти `mzaboot`, `mzbcss*`, `mzdjs*`, `mzerun` — вони досі зареєстровані, але ніде не підключені).
- Шрифт Inter Tight підтягується з Google Fonts, GT Pressura — із Webflow Fonts.
- Порожні ассети `mazda-style-v1.js`/`mazda-anim-v1.js` з першої спроби вже заповнені: це ті самі записи, дублів немає.
